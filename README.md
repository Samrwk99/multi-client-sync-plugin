### Multi Client Sync
This project contains both a Sillytavern plugin and extension that sync up multiple tabs open connected to the same Sillytavern instance.
It supports chat streaming, avoids having the same chat overwritten by another tab's useage and has the option to stop generations in another tab.

To work both the extension and the plugin must be installed.
You will need to set ```enableServerPlugins: false``` to ```enableServerPlugins: true``` in config.yaml in your sillytavern directory.
